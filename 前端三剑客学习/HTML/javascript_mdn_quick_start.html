开始阅读 直接看练习

先建立整体印象

JavaScript，简称 JS，是网页里的“行为层”。HTML 负责页面有什么，CSS 负责它长什么样， JS 负责用户操作之后发生什么。

HTML

像骨架。它告诉浏览器：这里有标题、段落、图片、按钮、表单。

CSS

像衣服和排版。它控制颜色、大小、位置、间距、动画。

JavaScript

像动作和逻辑。它处理点击、输入、计算、切换内容、请求数据。

先这样理解： JS 不是只能写网页，也可以运行在 Node.js 等环境里。但你现在学 WebGIS 和前端，先把“在浏览器里控制网页”这条线学清楚。

你第一阶段的目标

  • 能读懂简单 JS 代码。
  • 能声明变量、判断条件、循环处理数组。
  • 能写函数，把重复逻辑打包。
  • 能找到网页元素，并在点击、输入后修改页面。
  • 能打开控制台，看报错，知道大概错在哪里。

JS 写在哪里

初学时你会遇到三种写法。建议先用第 2 种，清楚、稳定、好维护。

1. 写在 HTML 文件的 script 标签里

适合小练习。通常放在 </body> 前面，这样页面元素已经加载出来了。

HTML 中直接写 JS 
<button id="btn">点我</button>

<script>
  const btn = document.querySelector("#btn");

  btn.addEventListener("click", function () {
    alert("按钮被点击了");
  });
</script>

2. 写在单独的 .js 文件里

适合正式一点的页面。HTML 管结构，CSS 管样式，JS 管交互。

推荐写法 
<script src="./main.js"></script>

3. 浏览器控制台里临时写

适合测试一句代码。打开页面后按 F12，进入 Console，就可以输入：

console.log("你好，JavaScript");

变量与数据

写程序的第一件事，是把数据存起来。变量就是给数据取名字。

变量：用 const 和 let

变量基本写法 
const city = "北京";  // 不打算重新赋值，用 const
let zoom = 12;       // 以后可能会变，用 let

zoom = 14;
先别用 var： MDN 会介绍 var，因为它是 JS 历史的一部分。但初学阶段先用 const 和 let，更接近现代写法，也更少踩坑。

常见数据类型

类型 例子 先这样理解
字符串 String "WebGIS" 文字。用引号包起来。
数字 Number 12、3.14 整数、小数都可以。
布尔 Boolean true、false 只有真和假，常用于判断。
空值 null null 主动表示“这里现在没有值”。
未定义 undefined let name; 声明了，但还没给值。
数组 Array ["北京", "上海"] 一组有顺序的数据。
对象 Object { name: "图层", visible: true } 一组带名字的属性，适合描述一个东西。

字符串、数字、数组的常用动作

字符串

const name = "地图";
console.log(name.length);
console.log(`学习${name}`);

数字

const price = 20;
const count = 3;
console.log(price * count);

数组

const layers = ["道路", "建筑"];
layers.push("河流");
console.log(layers[0]);

判断、循环、函数

这三块是 JS 的基础骨架：根据条件选择，重复处理数据，把代码打包复用。

判断：if...else

当某个条件成立时，执行一段代码；不成立时，执行另一段代码。

判断成绩 
const score = 82;

if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("需要继续练习");
}

循环：for...of

当你有一组数据，要逐个处理时，用循环。

const cities = ["北京", "上海", "广州"];

for (const city of cities) {
  console.log(city);
}

函数：给一段逻辑起名字

函数可以接收参数，处理后返回结果。它最大的好处是：重复使用时不用复制粘贴。

function getTotal(price, count) {
  return price * count;
}

const total = getTotal(20, 3);
console.log(total);

常用运算符

类型 常见写法 意思
算术 + - * / % 加、减、乘、除、取余。
比较 > < >= <= === !== 判断大小、是否严格相等、是否不相等。
逻辑 && || ! 并且、或者、取反。
赋值 = += -= 保存值，或者在原值基础上改变。
记住一个好习惯： 判断相等时优先用 ===，它比 == 更直接，不容易因为自动类型转换而出现奇怪结果。

DOM 与事件

只学语法还不够。网页里的 JS 最常见任务，是找到页面元素，然后在用户操作后修改它。

DOM 是什么

浏览器会把 HTML 页面变成一棵可以被 JS 操作的结构，这个结构叫 DOM。你可以把它理解成： JS 看到的网页对象模型。

三步写出网页交互

找到元素

用 document.querySelector() 选择页面上的标签。

监听事件

用 addEventListener() 等待用户点击、输入、移动鼠标。

修改页面

改文字、样式、类名、属性，或者添加新的元素。

点击按钮修改标题 
<h1 id="title">你好，JavaScript</h1>
<button id="btn">修改标题</button>

<script>
  const title = document.querySelector("#title");
  const btn = document.querySelector("#btn");

  btn.addEventListener("click", function () {
    title.textContent = "我已经开始学 JS 了";
    title.style.color = "teal";
  });
</script>

对象和常用内置工具

MDN 的“参考”部分很大，里面列了很多标准内置对象。初学时不用全背，只需要知道哪些经常用，哪些以后查。

对象：描述一个东西

const layer = {
  name: "道路图层",
  visible: true,
  opacity: 0.8

console.log(layer.name);
console.log(layer["opacity"]);

报错与调试

会调试，比一开始就写对更重要。初学 JS，报错不是坏事，它是在告诉你哪里需要看一眼。

先认识三类常见错误

SyntaxError

语法错，比如少了括号、引号、花括号。

ReferenceError

变量找不到，比如名字拼错，或者还没声明就使用。

TypeError

类型不对，比如把不是函数的东西当函数调用。

调试流程

  1. 打开浏览器控制台，看红色报错。
  2. 先看报错文件名和行号。
  3. 在可疑位置前后加 console.log()。
  4. 确认变量值是不是你以为的那个值。
  5. 一次只改一个问题，刷新页面再看。
const userName = "小明";
console.log("当前用户名：", userName);
